# entreprise-linux-server
Building a production-inspired Linux infrastructure from the ground up while documenting every stage: SSH, system administration, automation, monitoring, containerization, CI/CD, and cloud deployment.

## Project Vision
This repository documents the progressive development of a production-inspired Linux infrastructure.

Rather than presenting a finished system, the project evolves incrementally as new technologies and engineering practices are implemented.

See [`docs/architecture.md`](docs/architecture.md) for the current architecture and its evolution.
